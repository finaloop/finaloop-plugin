# Finaloop plugin

Connect 1,000+ sources — Shopify, Amazon, Stripe, Meta, Google, banks, payroll, inventory — and run your business from a conversation with your AI assistant on accrual-grade accounting data. Ask anything: sales and profits, blended ROAS, true SKU margin, cash runway, anomalies. Build dashboards and schedule reports in plain English.

Every answer is reconciled to the penny — numbers you can defend in a board meeting.

## Install

Claude Code:

```
/plugin marketplace add finaloop/finaloop-plugin
/plugin install finaloop-ai@finaloop-plugins
```

Codex:

```
codex plugin marketplace add finaloop/finaloop-plugin
codex plugin add finaloop-ai@finaloop-plugins
```

## Connect your Finaloop account

Installing the plugin does not connect your account. After installing, sign in with your Finaloop account:

- Claude Desktop or claude.ai: Customize > Plugins > Finaloop > Connectors > Connect
- Claude Code: run `/mcp` and sign in to Finaloop
- Codex: run `codex mcp login finaloop`
